# 《移動的美術課》藝術史參考

這是給藝術老師 Akila 阿錡拉上課投影、自己創作時對照用的靜態網頁。對應 2026 年岡山文化中心聯展《蛻變》中的六幅壓克力風景畫：《朝陽》《流水》《原彩》《樹影》《暮色》《星空》。頁面最下方另有「創作過程」一節，整理系列構圖、金線與交界色、打底原則與〈星空〉的發想，給想學繪畫的人參考。

線上頁面：https://akila33-jpg.github.io/moving-art-class-masterworks/

## 使用方式

用瀏覽器打開 `index.html`，或開啟上面的 GitHub Pages 網址。手機、平板、電腦和投影都可以。點已嵌入的圖片可看大圖。創作過程一節可點選六幅色塊，對照金線、交界色與飛鳥；右下角有背景音樂開關，預設關閉，不會自動播放。

已嵌入的圖片都放在 `images/` 裡，暫時沒有網路時仍可看這些圖。館方觀看連結需要連網，上課前請先點一次確認。

## 著作權原則

- 只嵌入公有領域，或館方以 CC0、CC BY 等開放授權提供的圖像，並把來源與授權寫在每張卡片與 `SOURCES.md`。
- 仍有著作權、或館方影像需另行授權的作品，不放圖片，只提供官方觀看連結。
- 本頁是教學與個人創作參考，不是對外轉載或出版這些圖像的授權。

## 本地檔案

- `index.html`：完整頁面
- `site.css`、`site.js`：轉場與創作過程的互動（不依賴第三方套件；若腳本沒有載入，內容仍全部可見）
- `images/`：已縮成約 1600 像素長邊的 JPEG
- `audio/`：薩蒂《Gymnopédie No. 1》公有領域錄音（Ogg 與 MP3）
- `SOURCES.md`：作品出處、館方網址、影像與音樂授權
